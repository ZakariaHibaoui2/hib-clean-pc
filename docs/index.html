Careful with your PC

A clean-up app touches the parts of Windows people worry about most. This is how Hib Clean PC earns that trust.

  • It asks first

    The app opens without admin rights. Anything that changes system settings shows Windows' own permission prompt, and nothing happens if you say No.

  • Every change can be undone

    The old value is saved before each change and Undo puts exactly it back. It can make a restore point before bigger changes.

  • Only known cache folders

    The cleaner never leaves its list of cache folders, never follows shortcuts or junctions out of them and never touches your documents.

  • Nothing leaves your PC

    No account, no telemetry, no ads. The only network use is winget checking for updates and the ad-blocking test. Read the privacy notes

Tested on a real PC before release: 38 script checks, 49 accuracy checks, 36 app checks, 10 install checks and 13 admin checks.

Tests run in a sandbox folder and a throwaway registry key, so they never change your settings. Every number the app shows is checked against an independent source. The code is open under GPL-3.0.

Install in one line

  1. 1

    Press the Windows key, type powershell and press Enter.

  2. 2

    Paste this and press Enter:

    PS> irm https://zakariahibaoui2.github.io/hib-clean-pc/install.ps1 | iex
  3. 3

    Open Hib Clean PC from the Start menu or your desktop.

It installs to your user folder, adds Start menu and Desktop shortcuts, and appears in Settings > Apps so you can uninstall it like any app. Read the install script

Questions

Is it really free?

Yes. There's no paid version, no account and no ads. The code is on GitHub under the GPL-3.0 license.

Will cleaning delete my files?

No. It only cleans caches and temporary files that apps and Windows recreate. Your documents, photos, passwords and browser history stay. The Recycle Bin is only emptied if you tick it.

Windows says “Windows protected your PC”

That appears for apps without a paid signing certificate when you download the .exe. Use the one-line install to avoid it, or choose More info, then Run anyway.

Does it send anything over the internet?

No data about you or your PC. The only network use is winget checking for app updates when you open App updates, and a DNS test that shows whether ad blocking works.

Does ad blocking work on school or work Wi-Fi?

Some school and work networks, and VPNs, force their own DNS, so it may not apply there. You can switch back to Automatic at any time.

How do I uninstall it?

Settings > Apps > Installed apps > Hib Clean PC > Uninstall. Undo the changes it made from inside the app first if you want Windows exactly as it was.
